# Django Blog API

A simple RESTful API for a blog built with Django and Django REST Framework, featuring JWT authentication, CRUD endpoints, filtering, pagination, and versioning.

## Features

- JWT login (access + refresh tokens)
- Create, Read, Update, Delete (CRUD) posts
- Filtering and search on posts
- Pagination and ordering
- API versioning (URL path versioning)
- Permissions: users can only modify their own posts
